# **Curso de HTML5 e CSS3 do Básico ao Avançado**

Este repositório contém todos os exercícios, desafios e projetos realizados durante o **Curso de HTML5 e CSS3**, ministrado pelo professor **Gustavo Guanabara** no [Curso Em Vídeo](https://www.cursoemvideo.com/).

Tem como propósito acompanhar minha evolução no estudo da linguagem, aplicar conceitos fundamentais e funcionar como material de apoio para consultas posteriores.

## Conteúdo do curso

O curso foi dividido em cinco módulos, os quais abordam os seguintes conteúdos:

### Módulo 1

- Primeiros passos no desenvolvimento web
- Entendendo a Internet e seu funcionamento
- Do front-end ao back-end: papéis e linguagens
- Configurando o ambiente de desenvolvimento
- Primeiros códigos em HTML5
- Trabalhando com imagens, áudio e vídeo
- Introdução ao CSS3

### Módulo 2

- Cores que comunicam
- Tipografia para web, do conceito ao código
- CSS que escala
- Modelo de caixas como base do layout
- Do rascunho ao site responsivo

### Módulo 3

- Publicação de sites, CSS avançado e organização de projetos
- Do repositório ao site online
- Imagens de fundo e controle visual com CSS
- Projeto Cordel: técnica com propósito
- Tabelas no HTML5, com os cuidados certos

### Módulo 4

- Dominando iframes
- Criando e personalizando formulários
- Design Responsivo e Mobile First
- Projetos práticos

### Módulo 5

- Flexbox em linguagem direta
- Grid Layout para composições precisas
- Do estudo à entrega: seu portfólio online
